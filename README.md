
# ✍️ Django Blog

A simple blog web application built with **Django**, where users can register, create blog posts, and comment on other users' posts.

---

## ✨ Features

- 👤 User authentication (Login, Logout, Register)
- 📝 Create, read, update, and delete blog posts
- 💬 Comment on posts
- 🧑‍🤝‍🧑 View other users’ profiles and posts
- 🗂️ Homepage with list of all published posts
- 🔍 View post details with comments

---

## 🏗️ Tech Stack

- **Backend**: Python, Django
- **Database**: SQLite (default)
- **Frontend**: HTML, CSS 
- **Other**: Django messages framework, Django admin
